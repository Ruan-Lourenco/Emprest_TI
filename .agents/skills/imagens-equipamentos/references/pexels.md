# Pexels API e licença

- Documentação oficial: https://www.pexels.com/api/documentation/
- Busca: `GET https://api.pexels.com/v1/search?query=...&per_page=...`.
- Autorização: cabeçalho `Authorization` com chave local.
- Campos usados: `id`, `url`, `photographer`, `src.original`.
- Diretrizes: link visível para Pexels e, quando possível, crédito ao fotógrafo.
- Licença: https://www.pexels.com/license/ (confirmar termos vigentes antes da publicação).
- Uma busca textual não prova ausência de pessoas, logos ou texto. A aprovação
  visual é obrigatória, e a URL da imagem deve pertencer a `images.pexels.com`.
